# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.9] - 2024-01-06
### Added
- Support for IntelliJ 2023.3 and later. Thanks to [@Coffee0127](https://github.com/Coffee0127) ([#8](https://github.com/KikiManjaro/MarioProgressBar/pull/8)).

## [1.8] - 2023-01-25
### Added
- Character selection — choose between Mario and Luigi. Thanks to [@Godox](https://github.com/Godox) ([#4](https://github.com/KikiManjaro/MarioProgressBar/pull/4)).

## [1.7] - 2021-10-15
### Changed
- Replaced deprecated `JBUI#scale` calls with `JBUIScale#scale`. Thanks to [@benchi99](https://github.com/benchi99) ([#3](https://github.com/KikiManjaro/MarioProgressBar/pull/3)).

## [1.6] - 2021-05-04
### Changed
- Migrated to new JetBrains plugin API. Thanks to [@meganukebmp](https://github.com/meganukebmp) ([#1](https://github.com/KikiManjaro/MarioProgressBar/pull/1)).

## [1.5] - 2020
### Fixed
- Mario and Koopa Shell icon rendering issues. Thanks to 李磊.

## [1.4] - 2020
### Fixed
- Plugin description.

## [1.3] - 2020
### Fixed
- Resource loading paths.

## [1.2] - 2020
### Fixed
- Brick wall texture.

## [1.1] - 2020
### Fixed
- Plugin icon.

## [1.0] - 2020
### Added
- Initial release — Mario progress bar for JetBrains IDEs, based on Nyan Progress Bar.
